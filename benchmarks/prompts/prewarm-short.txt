Metal shader compilation is the hidden cost of the first GPU dispatch. Every compute kernel that the runtime has never seen on this machine must be compiled to machine code before it can run, and the compiler caches the result on disk so that later processes on the same machine can load it for free. A program that touches a large family of kernels at startup therefore pays a one-time compilation tax on a fresh install, while a restart of the same binary pays almost nothing. The practical fix is to run the real binary once at install time: it compiles exactly the kernels the deployment will use, keyed by the kernel source and the device, and the on-disk cache survives across restarts until the binary or the operating system changes.
